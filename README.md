# Neural Digit Recognizer

A machine learning project that recognizes handwritten digits from 0 to 9 using a neural network.

## 📌 Overview

The Neural Digit Recognizer takes an image of a handwritten digit as input, processes the image, and predicts the corresponding digit using a trained neural network model.

## 🚀 Features

- Handwritten digit recognition
- Recognizes digits from 0 to 9
- Image preprocessing
- Neural network-based classification
- Displays the predicted digit

## 🛠️ Technologies Used

- Python
- TensorFlow / Keras
- NumPy
- OpenCV
- Matplotlib
- Pillow
